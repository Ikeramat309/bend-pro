# Competitor synthesis

## Benchmark position

QuickBend is the benchmark because it combines broad bend coverage, bender profiles, diagrams, persistent values, a protractor, impossible-state signaling, and Multiple Bends. Its direct reviews show that users value both breadth and an interface that removes mental translation.

Bend Pro should not win by listing more formulas. It should win by making the field action, reference point, and physical outcome more obvious and by preserving an evidence trail.

## Patterns to adopt

| Competitor pattern | Bend Pro translation |
|---|---|
| Bender/model, conduit, and size visible on calculator | Persistent setup strip with an explicit `affects math` / `reference only` status |
| Diagram updates with inputs | Continuous steel-tube diagram driven by safe normalized geometry |
| Impossible values change state visibly | Blocking feasibility message and withheld unsafe marks |
| Detailed instructions available | Guide layer tied to the exact workflow/mode |
| Matching Centers and Matching Bends are distinct | One Matching Offset calculator with two clearly measured modes |
| Parallel Kick and Parallel Kick Forward are distinct | Illustrated geometry chooser; do not copy unexplained labels |
| Multiple Bends lays out a stick | Build a Run imports validated bend cards and keeps their references |
| User can enter custom bender data | Future calibrated profile path; researched data remains provenance-aware |

## Patterns to improve

- Reviews praise direct diagrams but also show confusion when a reference pipe will not change. Bend Pro makes reference state explicit and stable.
- A visible Google Play complaint rejects slider/stepper-only input. Bend Pro keeps direct fraction entry primary.
- Public discussions want bend order and bender-facing direction. Bend Pro treats these as result data, not optional prose.
- Competitor centerline/CLR claims may be valuable, but Bend Pro does not copy them beyond validated bender profiles.
- QuickBend's breadth can hide similar-sounding kick geometries behind menu names. Bend Pro starts those workflows with the physical picture.

## Other apps

iBend Pipe validates demand for one-screen live calculation, protractor support, bender profiles, bender-facing cues, and broad saddle/compound coverage. Its reviews also show the trust cost when selected bender/size is unclear.

Conduit Bender Elite reviews visible through Google Play emphasize that users compare apps on instructions, bender characteristics, and bend coverage, not math alone.
