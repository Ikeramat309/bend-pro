# Lead research upgrade report

## Outcome

The original package is now a decision package rather than a collection of plausible calculator notes. The review preserves its useful source discovery while correcting weak or incomplete conclusions.

## What was upgraded

|---|---|
| Five workflows | Added Parallel Kick 90s as a sixth, full research package |

| Download cache included a full dependency tree and a malformed one-shot generator | Generated dependencies and the stale generator were removed; manuals remain non-canonical cache with URL/page traceability |

## Highest-impact findings

1. **Compound 90 currently has a geometry naming problem, not just a UI problem.** `Square` cannot safely identify both source diagrams.
2. **Parallel Kick 90 is a family of jobs.** The first interaction must disambiguate the physical orientation.
3. **Matching Offset's exact angle is not automatically an executable field instruction.** The result must state how the angle and bend center will be reproduced.
4. **A reference pipe is state, not decoration.** It must remain fixed across edits and appear in every rack result.
5. **Build a Run is worth building.** Reviews show strong demand, but it should compose trusted calculators instead of pretending raw marks contain solved bend geometry.

## Evidence posture

- Math/procedure: Klein, Greenlee, Wheatland, IBEW Local 903, and relevant tool manuals.
- Competitor behavior: QuickBend public docs and official store listings.
- Product pain and vocabulary: direct app reviews and public electrician discussions.
- Facebook: public search did not expose usable electrician discussion content without login; no Facebook claim was invented or laundered through snippets.
- Local QuickBend pack: the previously named `E:\quick bend example` volume is not mounted in this session. Earlier user-provided screenshots remain contextual, but the missing path is not treated as reproducible evidence.

## Production impact

None. This report changes research artifacts only. It intentionally does not modify calculator engines, screens, routes, registry entries, or production documentation.
