# Back-to-Back 90 - current gap audit

## Correct foundations

- Direct mark equals the finished back-to-back distance.
- Measurement begins at the back of the first 90.
- Star is the core second-bend reference.
- Optional first stub/deduct belongs behind disclosure.

## Required refinements

- Make `from back of Bend 1` part of the hero, not helper copy.
- Attach Star, hook direction, and same-plane check to the diagram.
- Add the documented Tight-U alternate as an explicit mode or Guide action.
- State when the selected bender affects only the optional first deduct/reference mapping.
- Separate direct fit from gain/developed-length methods.

## Risk

The formula is simple enough that UI ambiguity is the primary failure source. A correct distance aligned to the wrong symbol or measured from the wrong place still scraps conduit.
