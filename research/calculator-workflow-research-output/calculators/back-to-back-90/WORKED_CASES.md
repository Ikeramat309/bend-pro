# Back-to-Back 90 - worked cases

## Direct method

Finished back-to-back distance = `24 1/2 in`.

Second mark = `24 1/2 in from the back of Bend 1`. Align Star. No deduct or gain changes this mark.

## Optional first stub

- Finished first stub = `29 1/2 in`
- Verified bender deduct = `5 in`

First Arrow mark = `24 1/2 in from the conduit end`.

If the finished back-to-back distance is also `24 1/2 in`, the two numeric marks happen to match but have different origins and references. The UI must never merge them.

## Tight-U example

- Finished back-to-back distance = `12 in`
- First stub height = `5 in`

Klein alternate adjusted value = `7 in`, then follow the Tight-U Arrow/hook procedure. This is not the standard Star mark and must appear only in the alternate state.

## Rejections

- zero/negative distance;
- stub at or below deduct;
- Tight-U adjusted value at or below zero;
- missing verified deduct blocks only the optional first-stub result, not the direct second mark.
