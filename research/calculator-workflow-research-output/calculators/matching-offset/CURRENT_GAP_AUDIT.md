# Matching Offset - current gap audit

## Correct foundations

- Two modes correspond to two physically different measurable lengths.
- Inverse trigonometry and consistency checks are appropriate.
- Exact angle should remain exact.

## Critical gap

The current experience returns an arbitrary angle but does not make clear how that angle and its bend center will be reproduced on a hand bender. This is why the original QA failed mark/reference completeness.

## Required corrections

- Replace formula-style field wording with illustrated `Along the Run` / `Along the Pipe` choices.
- Pair exact angle and center spacing as the hero.
- Add common/uncommon execution status from the selected bender/reference.
- Add center-finding Guide content.
- Demote shrink below the field action.
- Clarify that centerline match does not guarantee an identical curve when the original shoe/CLR differs.

## Product opportunity

A transparent common-angle comparison can make Bend Pro more useful than a black-box inverse solver: show the user exactly what would change if they choose an executable standard angle.
