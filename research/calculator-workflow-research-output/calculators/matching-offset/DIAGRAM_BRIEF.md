# Matching Offset - diagram brief

## Measurement chooser

Show the existing bent conduit in both cards:

- Along the Run: horizontal/projected vector between vertical center stations.
- Along the Pipe: vector on the sloped straight between the two centers.

Use the same rise vector in both so the difference is unmistakable.

## Hero diagram

- Reference conduit is a quiet ghost/outline.
- New steel EMT is the active layer.
- Two center wraps have order numbers 1 and 2.
- Center-spacing vector connects the wraps.
- Exact angle arc is anchored at Bend 1; a same-angle link points to Bend 2.
- A 180-degree rotation cue sits between the bends.
- Rise vector uses the same color as its input/result.

## Angle execution state

Common/supported angle: attach the bender cue to the angle arc.

Uncommon angle: attach an angle-tool badge and center-calibration badge to the arc. The value remains visible; it does not turn red as invalid.

## Collision/scale rules

- Keep angle label outside the sloped segment.
- Keep rise and center-spacing vectors on opposite perimeter lanes.
- For shallow angles, visually compress long straight length with a break cue and state `diagram compressed`.
- Never allow the reference ghost to be mistaken for a third conduit.

## Cases

Common 30-degree; uncommon 14-degree; shallow long offset; near upper supported angle; both modes; absolute marks; light/dark; smallest phone.
