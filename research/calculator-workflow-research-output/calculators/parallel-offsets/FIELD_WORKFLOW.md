# Parallel Offsets - field workflow

## Starting state

The user is planning or has already marked Pipe 1 of an equal-size rack. Every conduit will make the same rise with the same two bend angles.

## Quick Shift sequence

1. Measure center-to-center rack spacing, not clear gap.
2. Choose the bend angle used on all pipes.
3. Identify the physical Pipe 1 and the order to Pipe N.
4. Choose which conduit end the progressive marks move toward.
5. Apply each row's shift to **both** corresponding bend marks.
6. Bend each pipe with the same reference method and 180-degree rotation.
7. Assemble the first two and verify the gap through the diagonal before finishing the rack.

## Full Layout sequence

1. Add the common offset rise to calculate center distance between bends.
2. Add Pipe 1 Center 1 only if absolute from-end marks are wanted.
3. Mark every pipe from the same named end using its table row.
4. Bend in the same order and plane.

## Common failures

- Entering edge-to-edge gap instead of center-to-center spacing.
- Moving only the first mark on successive pipes.
- Reversing the progression because Pipe 1 is not physically identified.
- Measuring some pipes from the opposite end.
- Combining center marks with Arrow/deduct marks without conversion.
- Assuming mixed sizes will preserve the same outside gap with this equal-size model.

## Check

The center-to-center gap through the diagonal offset section should match the intended rack spacing. Final straight legs should remain parallel and the offset rises equal.
