# Bend Pro — Grok Calculator Workflow Study Package

This folder is a research prompt package for a two-hour, multi-agent Grok run.
It is designed to determine the correct field job, inputs, outputs, marks, bend
sequence, diagram information, and product boundary for Bend Pro's five newly
added workflows.

## How to use it

1. Keep Cursor open on `C:\Project` so Grok can inspect the current app.
2. Tell Grok to read this folder.
3. Paste the complete contents of `00_START_HERE_GROK.md` as the task prompt.
4. Allow Grok to create only:
   `C:\Project\research\calculator-workflow-research-output`
5. Give Grok the full two-hour research window and permission to use the
   parallel agents specified in `02_AGENT_ASSIGNMENTS.md`.
6. When finished, share the entire output folder with Bend Pro's lead for
   evidence review. Do not ask Grok to implement its recommendations.

## Package files

| File | Purpose |
|---|---|
| `00_START_HERE_GROK.md` | Complete master prompt to paste into Grok |
| `01_REPOSITORY_CONTEXT.md` | Project files, current implementations, benchmarks, and seed sources to inspect |
| `02_AGENT_ASSIGNMENTS.md` | Parallel specialist roles and cross-review requirements |
| `03_RESEARCH_QUESTIONNAIRE.md` | Universal field/product questions every specialist must answer |
| `04_DELIVERABLE_CONTRACT.md` | Exact output folder, files, tables, and specification format |
| `05_SOURCE_AND_QA_PROTOCOL.md` | Evidence grades, citation rules, conflict handling, and rejection conditions |
| `06_REVIEW_SCORECARD.md` | Weighted acceptance criteria for the final research |

## Scope

- Back-to-Back 90
- Matching Offset
- Parallel Offsets
- Compound 90
- Multiple Bends

Box Offset, Hydraulic Layout, production code changes, and new conduit materials
are explicitly out of scope.
